# aman-writing-voice

A portable writing-voice guide that lets any AI tool draft text the way I (Aman Ranjan Verma) write: plain, direct, friendly, short sentences, no em-dashes.

It was built from my own public and private writing (Slack, Jira, email, X, LinkedIn and Medium) from 2018 to 2026. Only style patterns and made-up examples are included. No raw messages or work content are in this repo.

## How to use it

- **Cursor / Claude skills:** drop `SKILL.md` into your skills folder (for example `~/.claude/skills/aman-writing-voice/SKILL.md`).
- **ChatGPT, Gemini or any chat tool:** paste the contents of `SKILL.md` into custom instructions or at the start of the chat, then ask: "Write this in Aman's voice."
- **Raw link:** point any tool at `https://raw.githubusercontent.com/arverma/aman-writing-voice/main/SKILL.md`.

## What it covers

Sentence length and rhythm, vocabulary I use and avoid, openings and closings, punctuation habits, how I explain technical ideas, humour and warmth, formatting, AI tells to avoid, structure for each use case (X, LinkedIn, Medium, Slack, email, Jira, work docs, assignments), and 15 example snippets.

It is refreshed monthly.
